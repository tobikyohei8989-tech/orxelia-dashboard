# ORXELIA: 見積もり催促・追客管理 — 競合と勝ち筋の初期評価

調査日: 2026-11-07 / 状態: 仮説・非公開の事業評価資料。販売承認ではない。

## 公式競合情報
- サクミル https://sakumiru.jp/ : 月額9,800円〜、見積・原価・請求・案件管理など統合型。
- FieldX https://fieldxapp.jp/ : 月額2,980円〜、一人親方向け請求漏れ防止、見積テンプレ、LINE文面など。
- Quotto https://quotto.app/ : 月額500円〜、見積・請求作成中心。
- コンクルー https://www.concrew.co.jp/tools/estimate-follow-up : 無料の追客時期・文面提案、端末内保存、手動送信。
- Set Plan https://setplan.app/ : 月額660円/人だが最低5ユーザー（月3,300円）、見積・案件管理等。

## 差別化の仮説（未検証）
ターゲットは紙/Excel/LINEで見積作成する一人親方・小規模設備業者。見積作成機能は不要。『提出済みの見積の返事待ちだけを忘れず管理』に特化する。デジタル苦手層が初回3分以内で登録できるかを検証。電話・LINEの連絡はユーザー自身が行い、外部への自動送信はしない。

## 最小機能候補
1. 案件名・提出日・金額（任意）・次回確認日だけ登録
2. 今日確認すべき案件を大きく表示
3. ワンタップで電話/LINE連絡用の短文をコピー（自動送信しない）
4. 受注・保留・失注をワンタップ更新
5. CSVバックアップ/復元とデータ削除

## 削る候補
見積書作成、請求書、顧客CRM、複雑な営業分析、AI自動送信、会計連携、多人数権限。機能を削ることで顧客価値が上がるかは検証が必要。

## 反証条件・販売前のゲート
- Excel/カレンダー/無料追客ツールで十分であり、有料にする動機が弱い
- 入力が増え、紙より遅くなる
- 連絡忘れが受注・作業時間の実損に結びつかない
- データ消失・誤通知・プライバシー対策が不十分
- iPhone実機と保存/復元、異常系、継続使用を未検証
- 決済/解約/サポートと法務表示が未整備

## 売上予測の作り方
月売上 = 月額単価 × 有料継続顧客数。顧客数は流入×転換率と解約率で月ごとに積み上げる。悲観/基準/楽観の数値は実測の流入・転換・解約データがないため現時点で信頼できる予測を出せない。試算と予測を混同しない。決済手数料、運用費、サポート工数、税の仮定を必ず別記。

## 次の検証
競合の追客・リマインダー機能の有無を深掘りし、実際の試作品の機能と比較する。架空データで登録→通知→連絡記録→完了→バックアップ→復元のE2E試験を行う。公開・課金・顧客への連絡はユーザーの個別承認まで行わない。
