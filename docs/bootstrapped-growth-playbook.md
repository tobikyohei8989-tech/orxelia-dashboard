# ORXELIA｜少人数SaaSの成功事例と販売判断ルール
更新: 2026-11-08

## 一次情報と事実
- Tally: https://blog.tally.so/how-we-grew-tally-to-4m-arr-fully-bootstrapped/ （2025-10-15）: 2025年10月にARR約400万ドルと公表。フォーム作成の単機能集中、無料体験、製品経由の認知、利用者との共同改善。顧客コミュニティが重要で、完全無接触モデルではない。
- Pieter Levels: https://levels.io/projects/ （2026-09-08更新）: 多数の成功・失敗事業を公開。多数作れば必ず成功するわけではなく、成功例の選択バイアスに注意。
- Kit: https://kit.com/handbook/our-story : クリエイターへ絞り、紹介制度を導入。初期には直接営業と手作業移行支援も実施。ORXELIAにはそのまま転用できない。
- Buffer: https://buffer.com/about : 狭い課題から始め、透明性と継続改善を重視。
- Carrd: https://sfbl.beehiiv.com/p/carrd-case-study : 初期の顧客獲得に既存の発信者ネットワークとProduct Huntを利用。製品内の紹介導線が機能するのは、公開物を生成する性質があるため。第三者事例なので数値は別途検証。

## ORXELIAが採用する原則
1. 単機能に絞る。競合より多機能を目指す前に「1つの明確な成果」を提示。
2. 顧客獲得の経路を開発前に調査。検索意図・既存サイト・無料代替・比較キーワードを根拠URL付きで記録。
3. 直接営業・知人紹介・個別インタビューを必須条件にしない。公開情報の調査と、公開承認後のセルフサービス利用データを段階的に用いる。
4. SEOだけで成功するとは仮定しない。自然検索の難易度、競合コンテンツ、無料ツールの実用性を検証。
5. プロダクト主導の拡散は利用者が成果物を外部共有する場合に限って評価。社内専用ツールにウイルス的成長を仮定しない。
6. 無料プランは原価とサポート負荷が成立する場合のみ。無制限無料は導入しない。
7. 価格・収益・継続率・CAC・広告費・AI APIコストは観測と仮説を分離。
8. Geminiは独立反論者。429時は保留してChatGPTの公開情報調査を継続。AIの意見を市場検証の代替にしない。
9. 試作品完成時はユーザーの確認・承認が必要。外部公開、営業連絡、課金、販売開始は別途最終承認。
10. 競合優位性と現実的な流入経路が見つからなければ、新規開発を増やさず保留・撤退。

## 新規案件の評価票
- 顧客課題: 公開根拠URLと鮮度、代替手段
- 競合: 直接競合3件以上を目標（存在しない場合はその旨記録）、公式価格、機能、弱点
- 獲得経路: 具体的な検索クエリ、コンテンツ候補、無料ツール、第三者紹介の成立条件
- 最小製品: 3機能以内を原則、成果指標を1つ
- 価格・採算: 月額料金、決済費、推論費、サーバー費、サポート負荷、損益分岐
- 撤退条件: 検索需要不明、差別化不可、無料代替で十分、法務リスク、集客費が回収不可
- 状態: researched / hypothesized / implemented / tested / customer-validated を混同しない

## 見積もり催促・追客管理への暫定適用
既存のExcel/PDF見積書を変えず、次回連絡日・結果・通知の最小機能に絞る。公開レビューで追客漏れの課題を裏付ける。『見積提出後の連絡忘れチェック』の無料セルフチェックを検討。ただし無料ツールからの流入・有料転換は未実証。試作品のユーザー承認前に公開しない。
