# ORXELIA AI協業運用（2026-11-08）

## 役割と制約
- ChatGPT: ユーザーとの対話・定期タスク・接続ツール経由で一次情報調査、競合比較、勝てる条件の検証、Supabaseへの記録を主導。ChatGPT Plus契約はGitHub Actionsで利用できるOpenAI API契約ではない。
- Gemini: ChatGPTの調査結果に対する独立した反論、盲点、機能削減案、試作品生成。無料枠429時は保留し、事実の捏造や販売承認への自動昇格を禁止。
- GitHub Actions: コードの生成・試験・定期実行。根拠が無い場合は「未検証」と記録。
- Supabase: 調査根拠と検証結果の保存。既存の sales_review.chatgpt_competitor_research に出典URL、価格、機能、検証状況を記録。

## Geminiへの独立レビュー用入力
以下はChatGPTが公式URLを根拠にまとめた競合調査です。まずこの調査の誤り・競合の見落とし・無料代替の強さを批判し、勝てる条件と撤退条件を提示してください。追加機能を増やす前に、削るべき機能と最低限の実証実験を提案してください。未検証の価格、実績、法務、需要を断定せず、出典のない主張は仮説と明記してください。JSONで {objections:[],missing_evidence:[],minimal_features:[],kill_criteria:[],experiments:[]} を返してください。

## 承認ゲート
- 試作品完成時：ユーザーによる試作品確認・承認必須。
- 販売開始時：別途ユーザーの最終承認必須。
- ブラウザ簡易検査、競合URL取得、Geminiの意見だけでは販売可能と判定しない。
- 研究プランを作っただけでは調査完了にしない。
