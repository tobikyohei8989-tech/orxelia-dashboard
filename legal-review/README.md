# ORXELIA 法務審査ゲート（作業ブランチ・未接続）
これは全事業共通の法務審査判定ロジックです。既存ダッシュボード、Supabase、Netlify、Stripeには未接続です。
必須7項目のpassed・根拠・確認日・確認者、重大未解決リスクがないこと、審査バージョンを条件に開発承認申請可能とします。
開発は本人の明示承認が必要です。公開・決済・販売・支出は別承認とし、本モジュールは公開許可を返しません。
法的適合性を保証するものではなく、専門家判断が必要ならexpert_reviewで保留します。
テスト: node legal-review/legal-gate.test.mjs
